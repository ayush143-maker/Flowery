# Flowery

A small animated sunflower-themed web page built around the invitation “Have a flower.” The experience is contained in the top-level `index.html`, which presents a dark backdrop and a central blooming flower. No additional controls are described.

## Open and review locally

No package installation is needed. Open `index.html` in a browser, or serve the folder from the repository directory:

    python -m http.server 8000

Then visit http://localhost:8000. After editing, reload the page and review its layout at desktop and mobile viewport sizes. Keep the flower and message central.

No hosting provider or provider-specific deployment steps are documented. The page can be served as static content; no additional deployment configuration is described.
