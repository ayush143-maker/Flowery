# Flowery

A small animated sunflower-themed web page built around the invitation “Have a flower.” A dark backdrop and central blooming-flower presentation keep the experience focused on a brief visual moment.

## Open locally

No package installation is needed. Open `index.html` in a modern browser, or, from the repository directory, serve the folder with:

    python -m http.server 8000

Then visit http://localhost:8000.

## Making changes

The experience is contained in `index.html`. Keep the flower and message central, and test the page at desktop and mobile sizes.
