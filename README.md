# Flowery

**Flowery** is a small, animated sunflower-themed web page built around a simple invitation: “Have a flower.” The experience uses a dark backdrop and a central blooming-flower presentation to turn a short message into a lightweight visual moment.

## Open locally

The project is a standalone HTML page, so no package installation is needed. Open index.html in a modern browser. To preview it through a local server instead:

    python -m http.server 8000

Then visit http://localhost:8000.

## Making changes

The experience is contained in index.html. Keep the flower animation and message as the focus, and test the page on both desktop and mobile-sized screens. If you add images, audio, or separate scripts later, keep their paths relative to the page and document any new setup requirements here.
